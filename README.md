# MCA Connect

Build a complete modern MCA Student Portal web application for Mailam Engineering College.

Project name:

MCA Student Portal

Purpose:

This application is a centralized digital platform for MCA students and faculty to manage academic information, attendance, timetable, assignments, study materials, announcements, results, profile information, and communication.

IMPORTANT:

Do not create a generic AI-generated dashboard.

The UI must look like a professionally designed college technology platform.

Design requirements:

- Modern premium UI

- Clean and minimal layout

- Professional academic/technology aesthetic

- Responsive on desktop, tablet and mobile

- Smooth animations

- Beautiful cards and sections

- Consistent spacing and typography

- Modern icons

- Subtle glassmorphism where appropriate

- Good accessibility

- Avoid excessive gradients

- Avoid overly colorful UI

- Make the interface look unique and production-ready

Create the following main pages:

PUBLIC:

1. Home

2. About

3. Contact

4. Student Login

5. Student Registration

STUDENT:

6. Student Dashboard

7. Profile

8. Attendance

9. Timetable

10. Assignments

11. Study Materials

12. Announcements

13. Results

14. Notifications

15. Settings

ADMIN/FACULTY:

16. Admin Dashboard

17. Student Management

18. Attendance Management

19. Assignment Management

20. Study Material Management

21. Announcement Management

22. Results Management

Create proper routing between all pages.

For now, use realistic mock data.

Do not leave pages empty.

Every page should contain meaningful UI components and sample data.

Create a reusable design system and reusable components for:

- Navbar

- Sidebar

- Cards

- Tables

- Buttons

- Forms

- Modals

- Notifications

- Badges

- Empty states

- Loading states

The application should be structured so that a real database and authentication can be connected later.
